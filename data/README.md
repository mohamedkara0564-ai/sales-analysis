# Analyse des ventes e-commerce

## Objectif

Analyser les ventes d'une entreprise e-commerce afin de comprendre les performances commerciales, les produits, les marchés et les comportements clients.

## Questions métier

- Quel chiffre d'affaires est généré ?
- Comment les ventes évoluent-elles dans le temps ?
- Quels produits génèrent le plus de ventes ?
- Quels pays et quels clients sont les plus importants ?
- Quels segments clients doivent être ciblés en priorité ?

## Dataset

Le projet utilise le dataset **Online Retail** de l'UCI Machine Learning Repository.

Il contient des transactions e-commerce réalisées entre décembre 2010 et décembre 2011.

Source : https://archive.ics.uci.edu/dataset/352/online%2Bretail
